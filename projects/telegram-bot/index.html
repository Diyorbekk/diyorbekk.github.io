⚡ Tizimning Qisqacha Arxitekturasi

Ushbu bot shunchaki oddiy matnli bot emas, balki Telegram Mini App (TMA) texnologiyasiga ega to'liq veb-ekotizimdir. Mijoz botdan chiqmasdan turib, xuddi odatiy saytdagidek tovarlarni ko'radi, savatga yig'adi va bir zumda to'lovni amalga oshiradi.

🔄 Bosqichma-bosqich Ishlash Mexanizmi

1

Foydalanuvchi So'rovi (Client)

Mijoz botga buyruq beradi yoki WebApp tugmasini bosadi. Telegram mijozi barcha parametrlarni xavfsiz shifrlangan holda uzatadi.

Telegram Client / React TMA
2

HTTPS Webhook & Validatsiya

Telegram Bot API serveri bizning Node.js backendimizga darhol webhook POST so'rovini yo'llaydi. So'rov ichidagi initData HMAC-SHA256 yordamida haqiqiyligi tekshiriladi (hujum va soxtalashtirishdan himoya).

Node.js • Express • HMAC-SHA256
3

Ma'lumotlar Bazasi & Holat Nazorati

PostgreSQL bazasidan mahsulotlar soni (qoldiq) tekshiriladi. Redis orqali har bir foydalanuvchining aktiv sessiyasi va savatchasi keshda saqlanadi (baza ortiqcha yuklanmaydi).

PostgreSQL • Redis • Prisma ORM
4

To'lov Shlyuzlari (Click / Payme)

Mijoz to'lov qilishni tanlaganda, to'g'ridan-to'g'ri to'lov havolasi (Invoicing) generatsiya qilinadi. To'lov o'tgach, to'lov tizimidan serverga tasdiq keladi.

Click API • Payme Merchant API
5

Avtomatik Xabarnoma & Kuryer Guruhiga Jo'natish

Buyurtma tushishi bilan do'kon adminlarining yopiq Telegram guruhiga kuryer uchun xaridorning geolokatsiyasi va telefon raqami yuboriladi. Mijozga esa elektron chek yetkaziladi.

Telegram Bot Broadcast • Geolocation

💡 Texnik Afzalliklar: Nega bu yondashuv tanlangan?

🚀 Bizning Yechim (Webhook + WebApp)

  • 0.1 soniyalik javob tezligi (Instant)
  • Server resursini tejaydi (bo'sh qolmaydi)
  • Foydalanuvchiga zamonaviy ilova qulayligi
  • Xavfsiz to'lovlar va avto-kvitansiya

⚠️ Eskirgan Usul (Long Polling + Oddiy Bot)

  • Har soniyada so'rov berib serverni charchatadi
  • Murakkab savatcha yasab bo'lmaydi
  • Rasmlar va mahsulotlarni ko'rish noqulay
  • Yuklama ko'payganda qotishlar ro'y beradi
